# 06: 交叉复核与正式报告

**What to build:** 交付可用于后续决策的完整深度审计报告，清晰展示采用覆盖、问题、合理例外与证据边界。

**Blocked by:** 02: 应用导航与会话访问审计；03: 输入与待发送管理审计；04: Lexical 编辑器集成审计；05: 对话内容与 Streamdown 审计。

**Status:** ready-for-agent

执行门禁：尚未授权开始。

- [ ] 汇合全部分区证据，核对基线一致性、覆盖遗漏、重复发现及冲突结论。
- [ ] 每项发现包含规范依据、精确源码定位、用户影响、分级理由与建议。
- [ ] 明确区分组件遗漏、语义偏差、合理保留与未验证项；旧结论全部重新裁定。
- [ ] 分开记录源码、自动化回归与无头真实应用证据，不把环境缺口写成通过。
- [ ] 正式报告落入用户指定的 reports 目录及项目日期分类结构。
- [ ] 只形成报告，不实施修复、不启动额外工作或发布外部 issue。
