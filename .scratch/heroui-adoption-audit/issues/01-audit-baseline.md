# 01: 确立审计基线与覆盖清单

**What to build:** 为完整审计建立可复核的版本、规范、生产入口、控件归属及验证环境基线，避免后续分区遗漏或采用不同判据。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

执行门禁：当前仅计划落盘，尚未授权开始；依赖就绪不等于执行授权。

- [ ] 重新核对 HeroUI 解析版本、匹配源码与本地设计原则，区分官方规则与项目严格采用标准。
- [ ] 枚举所有生产界面、共享控件和第三方交互路径，给每项指定唯一分区归属。
- [ ] 核对现有无头验证入口、测试工具和运行环境，记录缺失项，不安装或构建原生后端。
- [ ] 明确验证使用的隔离状态、资源身份和禁止触碰的真实业务数据。
- [ ] 返回带基线身份的证据包，足以独立复核并启动四个分区。
