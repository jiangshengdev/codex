# Install and Launch Codex GUI

This page is for users trying Codex GUI for the first time.

## 1. Install Codex {/* #1-install-codex */}

<Tabs groupId="package-manager" defaultValue="npm">
<TabItem value="npm" label="npm">

```bash
npm install -g @jiangshengdev/codex@latest
```

</TabItem>
<TabItem value="pnpm" label="pnpm">

```bash
pnpm add -g @jiangshengdev/codex@latest
```

</TabItem>
<TabItem value="yarn" label="Yarn Classic">

```bash
yarn global add @jiangshengdev/codex@latest
```

</TabItem>
<TabItem value="bun" label="Bun">

```bash
bun add -g @jiangshengdev/codex@latest
```

</TabItem>
</Tabs>

## 2. Launch Codex {/* #2-launch-codex */}

Go to your project directory, then run:

```bash
cdx
```

## 3. Get the GUI Address {/* #3-get-the-gui-address */}

Enter:

```text
/gui
```

`/gui` only prints access URLs; it does not open a browser automatically.

The output looks like this:

```text
Local: http://127.0.0.1:<PORT>/task/<TASK_ID>#token=<ACCESS_TOKEN>
LAN:   http://<LAN_IP>:<PORT>/task/<TASK_ID>#token=<ACCESS_TOKEN>
```

- Use `Local` when accessing the GUI on the computer running Codex.
- Use `LAN` when accessing it from another device on the same local network.
- The port, task ID, and access token may change each time. Use the actual terminal output.
- Copy the full URL, including `/task/...` and `#token=...`. Do not share or publish the access token.

## 4. Open Codex GUI {/* #4-open-codex-gui */}

Copy the `Local` URL from the output, paste it into your browser's address bar, and open it.
