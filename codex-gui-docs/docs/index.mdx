# Codex GUI

本页适用于当前 fork 的普通用户。

## 1. 安装 Codex

```bash
npm install -g @jiangshengdev/codex@latest
```

## 2. 启动 Codex

进入你的项目目录，然后运行：

```bash
cdx
```

## 3. 启动当前任务

在 Codex 中发送一条消息，启动当前任务。

## 4. 获取 GUI 地址

输入：

```text
/gui
```

`/gui` 只会输出访问地址，不会自动打开浏览器。

## 5. 打开 Codex GUI

复制输出中的 `Local`，粘贴到浏览器地址栏并打开。
