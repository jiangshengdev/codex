# Codex GUI

本页适用于首次使用 Codex GUI 的普通用户。

## 1. 安装 Codex

```bash
npm install -g @jiangshengdev/codex@latest
```

## 2. 启动 Codex

进入你的项目目录，然后运行：

```bash
cdx
```

## 3. 获取 GUI 地址

输入：

```text
/gui
```

`/gui` 只会输出访问地址，不会自动打开浏览器。

输出类似：

```text
Local: http://127.0.0.1:55426/task/01a02882-0483-7c03-9712-647a9fbb971b#token=YOUR_ACCESS_TOKEN
LAN:   http://192.168.1.11:55426/task/01a02882-0483-7c03-9712-647a9fbb971b#token=YOUR_ACCESS_TOKEN
```

- 在运行 Codex 的电脑上访问时，使用 `Local`。
- 从同一局域网内的其他设备访问时，使用 `LAN`。
- 端口、任务 ID 和访问令牌每次可能不同，请以终端的实际输出为准。
- 必须复制完整 URL，包括 `/task/...` 和 `#token=...`。访问令牌不要分享或公开。

## 4. 打开 Codex GUI

复制输出中的 `Local`，粘贴到浏览器地址栏并打开。
