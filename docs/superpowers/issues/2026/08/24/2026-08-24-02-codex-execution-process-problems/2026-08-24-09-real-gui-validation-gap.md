## 问题

现有验证偏重类型、lint、单元测试和 Browser 测试中的机械断言，但没有稳定覆盖真实页面中的几何关系、视口裁切、浮层方向、焦点状态和组件视觉契约。

当验证只证明 DOM 节点存在、事件可触发或预设断言通过时，候选面板仍可能溢出、向错误方向展开，迁移后的输入组件也可能丢失原有默认、hover、disabled、invalid 或 `focus-visible` 状态。未实测布局时，代理还曾把视觉空隙归因于错误 CSS 属性，修改和验证后又撤销。
