# 手机访问 Codex GUI 时消息显示不完整

## 状态

- 记录中，未定位根因，未修复。

## 现象

用户反馈：手机访问当前 Codex GUI 时会缺消息，表现为 web 端看到的消息内容不完整或与预期不一致。

## 已确认事实

- 问题发生在手机访问 GUI 的场景。
- 当前还没有完整复现步骤、具体缺失的是历史消息、当前输入消息、流式增量，还是提交后的最终消息。
- 该问题可能和输入法组合态提前提交有关，但目前不能把两者直接合并为同一个根因。

## 需要补充的信息

- 手机访问的 URL 类型：`Local`、`LAN`、`VPN` 或其他代理地址。
- 缺失发生的阶段：页面初次加载、消息流式输出中、输入发送后、刷新后，或恢复会话后。
- 桌面浏览器和手机浏览器在同一 thread 上看到的 transcript 差异。
- 是否只在中文输入法、候选词确认、换行或 Enter 行为附近触发。

## 后续建议

- 先做只读复现记录：同一 thread 同时打开桌面和手机 web，记录缺失消息的具体 entry、时间点和操作步骤。
- 再沿 `codex-gui` 的 transcript/projection 数据流排查，避免先把问题归因到输入法或渲染层。
