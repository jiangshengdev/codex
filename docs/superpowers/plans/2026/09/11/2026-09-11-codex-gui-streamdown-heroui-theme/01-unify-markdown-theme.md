# 01：统一 Streamdown 的 HeroUI 呈现

**What to build:** 所有现有 Streamdown 内容以 HeroUI 语义主题呈现表格、代码和控件，恢复默认行内代码；静态与流式入口保持一致，现有外层角色语义保持不变。

**Blocked by:** 无其他任务；执行前须完成统一的设计与计划文档提交屏障。

**Status:** ready-for-agent（拆分已确认，执行仍需计划执行授权）

- [ ] 表头不再将次要文字色当作背景，浅深主题均可读。
- [ ] 完整代码块、表格和控件获得完整且不泄漏到外部的主题映射。
- [ ] 行内代码恢复 Streamdown 默认组件，不保留额外自定义边框。
- [ ] 不显示代码行号，保留原文段落换行、现有光标，不启用渐入动画。
- [ ] 数学、链接、图片/HTML、安全和剪贴板能力边界不变。
- [ ] 现有纯文本和流式思考不被转换为 Markdown。
- [ ] 相关自动化回归、类型、lint、格式检查通过，记录修复前目标失败与修复后结果。
- [ ] 形成独立本地代码提交，不含无行为变化的顺序调整。
