# 02：完成真实 GUI 验收

**What to build:** 为统一后的 Markdown 呈现提供真实 GUI 验收闭环，使不同主题、屏宽和内容生命周期下的阅读及操作均满足设计，并完成范围内必要修正。

**Blocked by:** 01：统一 Streamdown 的 HeroUI 呈现。需要消费其代码提交及通过的自动化证据。

**Status:** ready-for-agent（等待前置任务及计划执行授权）

- [ ] 使用当前有效完整 GUI URL，在专用无头会话验收修改后的真实运行时。
- [ ] 检查浅深主题、宽屏与窄屏、不同角色内容，以及流式到静态转换。
- [ ] 长代码、宽表格和公式在适当容器滚动，不撑宽页面。
- [ ] 可用的复制、下载、表格全屏及键盘焦点行为正确；保留能力受限场景的原有行为。
- [ ] 发现的范围内问题独立修正提交并重验；不修改或并入已有提交。
- [ ] 区分自动化、真实 GUI 证据及未执行场景，不以静态或隔离测试代替真实流式验收。
- [ ] 执行记录形成独立本地提交，包含场景结果、限制、代码与修正提交身份，不记录访问 token。
- [ ] 最终合并状态满足完整设计和所有任务，不遗留临时兼容实现。
