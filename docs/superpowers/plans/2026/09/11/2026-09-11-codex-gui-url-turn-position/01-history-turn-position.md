# 01：历史预览支持 URL 定位

**What to build:** 用户打开 `/history/<threadId>?turnId=<turnId>&position=end` 后，在只读历史预览中看到目标 turn 的结尾；完整历史中没有该 turn 时显示最新位置和临时提示。建立当前聊天也能复用的定位能力，涵盖路由意图、展示页选择、渲染就绪及一次定位生命周期。

**Blocked by:** 无前置实现任务；实施仍受[共同门禁](plan.md)约束。

**Status:** blocked — 任务划分已确认，未决行为与技术核验待闭合，未获实施授权。

## 验收条件

- [ ] 合法 URL 等待完整历史就绪后，定位到指定 turn 结尾。
- [ ] 目标不在默认展示页时，自动选择正确页面；同一 turn 跨多个片段时选择最后片段。
- [ ] 结尾实际处于可读区域；无最终 assistant 文本的 turn 不因缺少文本节点而被误判不存在。
- [ ] 完整数据确实不存在目标时显示最新位置及含义为“未找到指定对话轮次”的临时提示。
- [ ] 加载中或读取失败不误报轮次不存在，原有失败与重试行为保留。
- [ ] 每次打开或刷新只定位一次，定位参数保留；完成后手动滚动与分页不被反复覆盖。
- [ ] 页面离开后，旧的待处理定位不会影响新页面。
- [ ] 无定位参数保持既有行为，历史预览不因定位而激活聊天。
- [ ] 复用现有页面级 Browser、路由与分页测试入口，覆盖上述外部行为；未运行的真实入口验证明确保留为未完成。

## 稳定交付与边界

交付历史预览的完整行为与可复用定位接口、相关回归证据。参数解析和分页选择各保留单一权威来源；不为两个页面建立重复定位路径。

接口稳定后才解锁任务 02。任务提交边界包含本任务行为和对应测试，不夹带无关重排。非法参数与路由重新进入语义以共同门禁闭合后的决定为准，本文不预设结果。
