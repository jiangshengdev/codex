# 01：完成富文本局部 HeroUI 样式适配

**What to build:** 所有现有 Streamdown 富文本及全屏表格在自身边界内消费 HeroUI 视觉语义，保留默认组件和已确认行为；全局主题及外部组件保持原有语义。

**Blocked by:** 无其他任务；实施前须完成设计与计划文档的独立提交。

**Status:** ready-for-agent（任务拆分已确认，执行等待计划确认）

- [ ] 不为富文本新增或重定义全局主题映射、工具类语义或 HeroUI 变量含义；带回退的全局映射也不允许。
- [ ] 表头、代码、行内代码和辅助控件在浅深主题下呈现正确的 HeroUI 表面、文字及边界颜色。
- [ ] 正文与全屏表格均有明确覆盖边界；无独立标记的菜单和控件也覆盖背景、文字、悬停及焦点状态。
- [ ] 恢复默认行内代码，保留默认代码块、表格和工具栏结构及 GitHub 浅深代码高亮。
- [ ] 无行号、原文段落换行、块状光标、无渐入动画、角色层次及数学和安全边界保持不变。
- [ ] 自动化穿过已有 transcript 入口，验证静态与流式一致、局部滚动和交互，以及外部 HeroUI 组件在挂载、卸载和全屏切换前后保持不变。
- [ ] 源码及构建规则审查证明没有全局主题重定义；不以根元素缺少富文本变量或外观暂时不变替代该检查。
- [ ] 相关自动化、类型、lint、格式检查及独立审查完成；失败明确记录，不通过豁免或放宽断言掩盖。
- [ ] 按计划提交门禁形成独立代码提交，不混入无行为变化的顺序调整或无关文件。
