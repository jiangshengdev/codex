# 02：连接恢复的成功与失败交互演示

**What to build:** 提供两条可以反复操作的完整恢复演示：点击重新连接后进入等待，随后确定成功或再次失败。成功移除恢复提示；失败提供说明、诊断和再次重试。模拟只控制预览内状态，真实反馈由产品组件渲染。

**Blocked by:** None (can start immediately)。直接依赖现有产品组件与 Storybook 环境，不依赖 ticket 01 的固定状态 Story；执行前遵守总计划公共门禁。

**Status:** ready-for-agent

- [ ] 成功与失败分别为结果确定的演示，不使用随机结果或外部网络。
- [ ] 点击后先进入可观察的重连中状态，等待期间不能重复触发。
- [ ] 模拟成功后移除连接恢复提示，不新增产品成功提示或真实连接副作用。
- [ ] 模拟失败后展示真实失败说明和诊断入口，并可重复重试同一演示。
- [ ] 诊断弹窗可以实际打开与关闭。
- [ ] 支持重新开始；重置和 Story 切换清理未完成操作，不继承旧结果或受到旧回调影响。
- [ ] 复用权威组件输入类型，局部模拟不成为产品连接状态的第二份实现。
- [ ] 演示控制复用 HeroUI，新增可见文案经 Lingui 提取、补译和重复提取稳定检查；真实业务文案直接复用。
- [ ] 自动化从可见交互验证两条路径、重复激活限制、重试、重置和隔离，不绑定内部定时器或状态变量。
- [ ] 对应 E2E 在现有三个浏览器项目中实际收集并通过，不建立真实业务连接或发送消息。
- [ ] 以独立任务提交交付，不导入 ticket 01 的新增 fixture 或 Story。
