# 01：连接恢复的独立状态 Story

**What to build:** 在 Storybook 中直接查看产品连接恢复提示的启动失败、连接中断、重连中、重连失败状态，使用真实组件、文案、重连按钮和诊断弹窗，并通过浏览器验证可见行为。

**Blocked by:** None (can start immediately)。无其他 ticket 依赖；执行前仍须通过总计划的实施授权与文档提交门禁。

**Status:** ready-for-agent

- [ ] 四种状态可独立打开，无需先操作其他 Story。
- [ ] 直接复用 `ConnectionRecoveryNotice`，输入使用权威类型或 props 派生类型，不复制内部 JSX 和业务文案。
- [ ] 启动失败与已有会话后的连接中断展示各自真实文案；不声称加载了真实会话。
- [ ] 重连中具有真实等待文案、加载指示和不可重复激活行为。
- [ ] 重连失败提供真实失败说明及诊断入口，模拟诊断文本不含真实敏感数据。
- [ ] 诊断弹窗可打开、关闭，键盘操作和关闭后的焦点返回可验证。
- [ ] 在现有中英文、浅深色环境和窄容器下内容可读，长诊断可滚动且无横向溢出。
- [ ] 所有回调限于本地预览，不启动产品连接生命周期或发送业务消息。
- [ ] 对应 Storybook E2E 在现有三个浏览器项目中实际收集并通过，所需静态与构建检查按总计划完成。
- [ ] 以独立任务提交交付，不依赖交互演示 ticket 的新增代码。
