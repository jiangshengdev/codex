# 01：打通基础真实渲染

**What to build:** 让最小真实组件在 Storybook 中使用产品相同的样式、主题基础和语言资源渲染，形成可直接检查的预览入口。

**Blocked by:** None (can start immediately)。实际执行仍受父计划的授权、环境预检和文档提交门禁约束。

**Status:** ready-for-agent

- [ ] 应用全局样式与 HeroUI 样式在实际预览中生效，不维护样式副本。
- [ ] 复用真实语言解析与目录加载，英文和简体中文均在首次组件渲染前激活。
- [ ] 默认跟随系统主题，基础 Provider 相对顺序与应用一致。
- [ ] 最小真实组件可在 Storybook 侧栏选择并显示；不扩展为完整业务状态目录。
- [ ] 实际构建支持应用 alias、React、Tailwind、Lingui；新增文件被类型及 lint 配置正确收集。
- [ ] 通过真实 Storybook 页面验证渲染和翻译，不能只用配置检查替代。
- [ ] 无真实业务连接和消息发送，不新增依赖或放宽检查。
- [ ] 相关类型、lint、格式、构建及聚焦回归通过，形成独立本地任务提交。

测试边界：Storybook 预览入口，复用既有国际化 Browser 测试方式。具体文件与命令由父计划管理。
