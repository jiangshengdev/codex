# 02：接入三态主题预览

**What to build:** 在 Storybook 中直接选择浅色、深色或跟随系统；选择只在当前页面有效。产品共用主题能力，但暂不开放切换入口。

**Blocked by:** 01：打通基础真实渲染。消费其已验证预览环境，不依赖任务 03。

**Status:** ready-for-agent

- [ ] 三段式图标控件始终选中一个主题偏好，支持键盘与辅助技术操作。
- [ ] 首次打开默认跟随系统；系统变化时自动更新最终深浅色。
- [ ] 显式选择浅色或深色后，不被系统变化覆盖；重新选择跟随系统后立即使用当前系统主题。
- [ ] 选中态表达偏好：系统实际为深色时，跟随系统项仍保持选中。
- [ ] 不持久化偏好；真实刷新和重新打开后均恢复跟随系统，不以组件重挂载代替该验收。
- [ ] 复用现有主题 owner 和 HeroUI 控件，不引入 Next.js、额外主题库或另一条主题应用路径。
- [ ] 产品继续跟随系统且不新增入口，完成相关真实应用无头验收。
- [ ] 新增可翻译名称有正确语言资源，生成后重复提取稳定。
- [ ] 相关回归及质量检查通过，形成独立本地任务提交。

测试边界：真实 Storybook 页面中的主题选择与刷新，产品共享 Provider 回归及真实应用无头验收。具体文件与命令由父计划管理。
