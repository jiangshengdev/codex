# 02：支持已有回答的反斜杠公式

**What to build:** 已有及新增助手回答中的反斜杠括号公式能够复用同一数学渲染链路，在实时输出与历史消息中分别作为行内或块级公式显示。

**Blocked by:** 01：接入助手回答的数学渲染。需要其已验证的助手专属数学配置、样式与消息入口。

**Status:** ready-for-agent

- [ ] 圆括号形式渲染为行内公式，方括号形式渲染为块级公式。
- [ ] 在普通 Markdown 消费转义之前识别公式，不从普通括号猜测公式。
- [ ] 行内代码、代码围栏、链接目标与明确转义的字面量不被误转换。
- [ ] 增量跨分隔符到达、公式闭合、结束及重新打开历史后的显示正确，原始消息不被修改。
- [ ] 不增加反斜杠公式专用补齐、占位或等待状态，沿用已确认的流式默认行为。
- [ ] 最小几何与代数样例正确渲染，不将私人聊天全文复制进测试。
- [ ] 四种语法共存及非助手消费者隔离的三浏览器回归通过，没有第二套数学排版实现。
- [ ] 本任务变更通过适用检查并形成独立本地提交；整体完成仍以计划的最终验证为准。
