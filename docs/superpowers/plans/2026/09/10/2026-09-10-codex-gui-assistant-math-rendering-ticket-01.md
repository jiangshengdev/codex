# 01：接入助手回答的数学渲染

**What to build:** 助手回答中的单美元、双美元公式在实时输出、完成后与历史消息中正常排版，使用现有数学插件与样式，并保持 Streamdown 默认展示行为。

**Blocked by:** None (can start immediately)。实际执行仍须满足已确认计划的授权与文档提交前置条件。

**Status:** ready-for-agent

- [ ] 单美元行内公式和双美元公式在静态、流式助手消息中产生实际数学输出；双美元保留 Streamdown 的上下文语义。
- [ ] 数学字体与样式加载成功，长公式及窄屏沿用依赖默认布局，没有新增缩放或滚动策略。
- [ ] 开启单美元解析，但不顺带开启单美元自动补齐；双美元保留默认流式补齐。
- [ ] 不完整与无效公式沿用默认处理，消息其余内容仍可阅读。
- [ ] 能力限定在助手回答，用户消息、思考内容和工具内容不受影响。
- [ ] 原始消息不变，保留分块边界、Markdown 安全规则及现有代码、表格、链接和复制行为。
- [ ] 现有消息入口的静态、流式及模式切换回归通过，包含三种浏览器的定向验证。
- [ ] 本任务变更通过适用检查并形成独立本地提交，无依赖安装、无远程操作。
