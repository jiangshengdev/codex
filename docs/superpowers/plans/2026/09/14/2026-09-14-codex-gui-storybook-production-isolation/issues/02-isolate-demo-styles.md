**Blocked by:** None (can start immediately)。不消费票据 01 的语言资源结果；实施阶段仍须先完成总计划规定的文档提交与环境预检。

**Status:** ready-for-agent

- [ ] Storybook 继续消费真实产品 CSS、HeroUI token 和已有依赖样式，不复制产品样式实现。
