# 01：隔离演示专用语言资源

**What to build:** 生产语言包不再携带演示专用说明和模拟控件消息，Storybook 继续正确展示中文、英文以及真实产品组件。主题切换控件及其他生产组件的消息仍归产品；共享消息只有一个翻译权威来源。本票交付从提取、翻译迁移、加载到实际构建产物与浏览器验证的完整路径。

**Blocked by:** None (can start immediately)。实施阶段仍须先完成总计划规定的文档提交与环境预检。

**Status:** ready-for-agent

- [ ] 仅隔离为演示创建的消息，不以当前调用者或目录名称重新判定生产能力归属。
- [ ] 主题切换控件、主题 Provider 和偏好能力保留产品归属，其有效翻译不被迁移到演示专用 catalog。
- [ ] 生产运行时只加载产品消息；预览同时获得产品消息和演示专用消息。
- [ ] 已有中英文翻译、placeholder、ICU 结构及 translator context 不丢失。
- [ ] 共享消息以产品翻译为权威，不维护第二份共享翻译，不靠运行时覆盖或缺失消息回退掩盖冲突。
- [ ] 使用项目提取入口生成并审查完整输出，重复提取稳定；迁移产生的 obsolete 状态明确处理，不清理无关历史消息。
- [ ] 实际生产语言产物没有演示专用消息，且保留产品消息，包括主题切换控件消息。
- [ ] Storybook 中英文与代表性场景交互通过，生产本地化回归通过。
- [ ] 生产构建继续检查 Story 和预览入口的 TypeScript，不扩大忽略或跳过检查。
- [ ] 独立审查闭环，并以独立本地提交交付；已提交内容的修正另建提交。
