# 04：引导与未发送恢复

**What to build:** 在 Storybook 中查看并手动推进引导成功、明确失败、结果未知，以及未发送消息的恢复过程，同时提供合法完整队列组合状态。

**Blocked by:** 01：队列查看与普通发送。消费其真实协调器、手动外部结果与隔离机制；不依赖 02 或 03 的新增操作场景。

**Status:** ready-for-agent

- [ ] 独立展示引导成功所需队列状态、明确失败后的优先发送、引导状态未知、未发送和恢复中。
- [ ] 可操作路径由手动控制推进请求结果与必要事件，不使用自动延迟或随机结果。
- [ ] 引导明确失败后展示真实优先发送预览、数量和加入队列反馈。
- [ ] 引导未知保留未知语义，不自动重发，不当作明确失败处理。
- [ ] 继续发送入口的可用和不可用条件符合产品；启动恢复后保持恢复中并限制重复操作。
- [ ] 手动推进恢复成功或再次失败，数量、消息和后续动作按真实协调器语义变化。
- [ ] 完整组合只呈现合法共存状态，不为拼满界面组合互斥标志。
- [ ] 完整组合展示不依赖其他票据新增 Story；跨编辑、排序与恢复的共同操作归最终汇合验收。
- [ ] 重置和切换使未完成的引导与恢复结果失效，场景不共享真实持久记录。
- [ ] 本票 E2E 覆盖成功、明确失败、未知与恢复限制，验证真实可见反馈而非局部模拟字段。
- [ ] 不新增产品恢复策略、兼容路径或真实网络通信。
