# 02：编辑、删除与内容保护

**What to build:** 在队列 Story 中编辑、取消和删除消息，并手动触发编辑失效，检查内容保留、复制以及放弃确认的完整过程。

**Blocked by:** 01：队列查看与普通发送。消费其稳定预览装配、真实协调器绑定与场景隔离能力；不依赖 03 或 04。

**Status:** ready-for-agent

- [ ] 同时提供正常编辑、删除确认和编辑失效的独立状态及可操作流程。
- [ ] 编辑与保存即时更新真实队列预览；空内容不可保存，取消保留原消息，不覆盖主输入草稿。
- [ ] 删除提供保留和确认路径；确认后数量与内容同步，删除最后一条后展示空态。
- [ ] 手动触发进入发送、目标 turn 关闭及会话失效，显示真实反馈并保留不能保存的编辑内容。
- [ ] 保留内容可复制，分别验证复制成功与失败反馈，不将点击记录视为复制成功。
- [ ] 放弃未保存内容前确认，可返回编辑；放弃编辑不误删原排队消息。
- [ ] 编辑占用和不可管理状态遵循产品限制，确认界面支持键盘与合理焦点返回。
- [ ] 使用 01 的隔离机制，重置和 Story 切换清除编辑、确认及旧操作结果。
- [ ] 本票 E2E 断言外部内容与行为，覆盖上述正常和失败路径；语言与组合覆盖由总计划最终汇合完成。
- [ ] 不修改产品编辑策略，不引入真实业务请求或产品调试入口。
