# 02：按四小时时段显示时间标签

**What to build:** 在聊天记录的 turn 分界处显示实际日期和时分。第一条消息前显示，此后只在跨本地日期或四小时时段时再次显示；贯通权威 turn 时间、当前与历史展示和回归验证。

**Blocked by:** None；无其他 ticket 阻塞。执行仍须通过计划授权与文档提交前置门禁。

**Status:** ready-for-agent

- [ ] 使用权威 turn 开始时间，不能把组件挂载时间作为真实时间，也不声称是点击发送时间。
- [ ] 每天按 00:00、04:00、08:00、12:00、16:00、20:00 划分六段，左闭右开。
- [ ] 第一条可确定时间显示标签；同日期同段不重复，跨段或跨日期显示新标签。
- [ ] 显示“今天 09:37”“昨天 16:42”“2026年9月10日 08:23”等实际时间，不显示区间或区间起点。
- [ ] 同一 turn 运行跨段不插入标签；多个 fragment 不重复标签。
- [ ] 缺失时间不显示占位或虚构值；没有消息的时段不产生空标签。
- [ ] context page、当前会话与历史详情使用同一规则，保持现有分块和折叠性能。
- [ ] 六段边界、跨日期、缺失值和部分历史场景通过行为验证；窄屏展示进入组合无头验收。

共享模型、fragment、catalog 与另一 ticket 存在写冲突，按计划资源锁协调；这不是产品阻塞依赖。
