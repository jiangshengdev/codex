# 01：每个 turn 显示实时与最终耗时

**What to build:** 每个 turn 的用户第一条输入下方显示一份耗时。运行中实时增长，包含等待；结束后固定权威耗时。贯通既有时间数据、聊天记录状态、当前与历史界面、本地化和回归测试。

**Blocked by:** None；无其他 ticket 阻塞。执行仍须通过计划授权与文档提交前置门禁。

**Status:** ready-for-agent

- [ ] 权威开始与耗时字段在基线、实时事件及历史读取中保留，缺失值不补造。
- [ ] 每个 turn 只在第一条用户输入下方显示一次；fragment、追加输入、折叠和分页不重复。
- [ ] 运行中显示“已用时 8秒”“已用时 2分钟 05秒”“已用时 1小时 03分钟 09秒”。
- [ ] 等待审批或回答期间持续计时；重连、切换界面不从零重启。
- [ ] 结束后采用最终耗时并显示“用时”；中断、失败不新增重复状态。
- [ ] 零耗时可显示，缺失耗时不显示，无一分钟门槛。
- [ ] 活动时钟不重渲染无关历史 chunk；沿用现有主题与中英文语言体系。
- [ ] 受影响状态和 Browser 测试通过，真实运行时场景进入组合无头验收。

共享模型、fragment、catalog 与另一 ticket 存在写冲突，按计划资源锁协调；这不是产品阻塞依赖。
