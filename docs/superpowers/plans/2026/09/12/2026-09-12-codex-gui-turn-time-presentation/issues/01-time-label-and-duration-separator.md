# 01：时间标签居中与耗时分隔线

**What to build:** 在聊天内容区域居中显示已有时间标签，在用户首条输入下方的耗时之后显示弱化细分隔线，让时间层级更清晰，同时保留现有分组与计时行为。

**Blocked by:** None (can start immediately)。实施须满足计划的统一授权与文档提交前置；不依赖 ticket 02。

**Status:** ready-for-agent

- [ ] 时间标签使用 HeroUI Typography，在内容区域水平居中，保留语义 time。
- [ ] 原有四小时时段、跨日期、实际开始时分及分页去重规则保持有效。
- [ ] 耗时保留首输入位置、运行中增长及权威终态口径，使用弱化小号文字与等宽数字。
- [ ] 耗时下方使用水平 HeroUI Separator tertiary，横跨内容宽度；耗时省略时不留下独立线。
- [ ] 普通宽度与窄屏验证居中、位置、唯一性和无横向溢出。
- [ ] 保留已有状态、折叠与 chunk 性能边界，受影响行为测试和项目检查通过。
