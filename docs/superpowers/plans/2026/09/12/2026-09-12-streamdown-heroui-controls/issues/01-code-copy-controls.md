# 01：代码块仅保留 HeroUI 复制

**What to build：** 静态与流式 Markdown 代码块使用 HeroUI 复制按钮，移除下载入口；保留代码高亮、原始复制内容和现有流式禁用行为，提供准确的成功或失败反馈。行内代码与正文不受影响。

**Blocked by：** None（无其他 ticket 阻塞；执行仍需主计划授权与文档提交、工作树预配门禁）。

**Status：** ready-for-agent

- [ ] 生产静态／流式 Markdown 入口都接入新复制控件，按钮有可访问名称，使用 HeroUI 的辅助操作语义。
- [ ] 代码块不再存在可见、隐藏或可通过键盘到达的下载入口，也不保留代码下载执行路径。
- [ ] 复制内容与原始代码一致，包含原有尾部换行；不从高亮 DOM 拼接或使用显示裁剪结果。
- [ ] 保留行内代码、围栏代码、高亮、语言标题、meta、incomplete、行号配置与代码滚动行为。
- [ ] 根据安全上下文和 writeText 能力显示代码复制入口；表格复制能力不限制代码复制。
- [ ] 流式禁用沿用 StreamdownContext.isAnimating；写入成功后才显示成功，拒绝时显示明确错误并允许重试。
- [ ] 本地化、浅色／深色主题与焦点样式符合应用约定；反馈定时资源在卸载时清理。
- [ ] 通过现有 Markdown 渲染接缝验证静态／流式、复制载荷、能力缺失、失败和重试；替换旧下载等待锚点但不删除相邻内容覆盖。
- [ ] 本任务完整受影响 Browser 文件、类型、lint、格式和 catalog 稳定性检查通过，形成独立本地行为提交。
- [ ] 不修改 Streamdown、不增加依赖补丁、扩展名映射、私有导入或临时兼容路径；不改正文解析或 transcript chunk 模型。

与表格任务的共同注册、样式、测试和 catalog 交集由主计划的独立工作树及集成节点处理，不形成 ticket 间阻塞。整体完成还需最终合并状态的组合验证与适用真实应用无头验收。
