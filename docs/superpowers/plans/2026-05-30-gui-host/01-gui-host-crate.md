# Codex GUI Host Crate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `port/lazy-proj-130` 已完成的 `codex-gui-host` crate 原样迁入当前 `dev`，恢复 browser-safe host shell。

**Architecture:** `codex-gui-host` 只负责本机 GUI host shell：loopback server、launch token、launch URL、Host / Origin 校验、`/ws` 首帧 `gui/authenticate`、allowlist、dev/prod assets 和 `GuiBackend` contract。它不依赖 `codex-app-server`，也不接入 `MessageProcessor`；后续 `02+` 计划才会把认证后的连接桥到 extra in-process connection。

**Tech Stack:** Rust 2024, axum, tokio, tokio-util, tower-http, tokio-tungstenite, serde_json, base64/rand.
