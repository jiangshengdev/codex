# rust-v0.133.0 dev Merge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Merge official `rust-v0.133.0` into `dev` while preserving the local thread projection overlay and fork-specific npm/update/release channel behavior.

**Architecture:** Use a clean integration branch, accept official 0.133 structure by default, then reapply only the minimum fork and projection overlay decisions documented in `docs/superpowers/specs/2026-05-23-rust-v0.133.0-dev-merge-design.md`. Handwritten workflow/source conflicts are resolved before generated app-server schema and TypeScript are regenerated.

**Tech Stack:** Git, GitHub Actions, Node.js launcher, Python packaging scripts, Rust app-server/app-server-protocol/TUI, app-server schema generator, Cargo tests, `just`.

Keep the upstream resolver shape:

```js
const packageBinaryPath = (vendorRoot) =>
  path.join(vendorRoot, targetTriple, "bin", codexBinaryName);
const legacyBinaryPath = (vendorRoot) =>
  path.join(vendorRoot, targetTriple, "codex", codexBinaryName);

function resolveNativePackage(vendorRoot) {
  const packageRoot = path.join(vendorRoot, targetTriple);
  const binaryPath = packageBinaryPath(vendorRoot);
  if (existsSync(binaryPath)) {
    return {
      binaryPath,
      pathDir: path.join(packageRoot, "codex-path"),
    };
  }

  const legacyPath = legacyBinaryPath(vendorRoot);
  if (existsSync(legacyPath)) {
    return {
      binaryPath: legacyPath,
      pathDir: path.join(packageRoot, "path"),
    };
  }

  return null;
}
```
