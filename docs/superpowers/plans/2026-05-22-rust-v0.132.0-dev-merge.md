# rust-v0.132.0 dev Merge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Merge official `rust-v0.132.0` into `dev` while preserving the local thread projection overlay and fork-specific release/update channel guards.

**Architecture:** Use an integration branch for the first merge, accept official 0.132 source behavior by default, then reapply only the minimum projection/fork overlay hooks. Generated app-server schema and TypeScript are regenerated after handwritten Rust source is coherent.

**Tech Stack:** Git, Rust, app-server, app-server-protocol, TUI, app-server schema generator, Cargo tests, `just`.

---
