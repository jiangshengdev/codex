# 压缩边界以稳定身份衔接历史和实时投影

历史决定：2026-08-15。补录日期：2026-09-30。

成功压缩用于划分已加载历史的展示页，方便查阅，不引入网络或性能分页。只有完成事实形成边界，空边界页和连续压缩均保留；同一轮次可跨页，消息正文仍唯一，状态与错误归于该轮最后片段。默认查看最新页，在旧页阅读时不因新压缩强制跳走，不展示内部压缩摘要。

为避免历史快照中的 synthetic 身份与实时 canonical 身份重复，新持久记录保留 canonical ContextCompaction 完成项，使快照和实时投影使用同一轮次与条目身份。采用限定的身份修正，不恢复全局历史 cursor，也不扩大为整体快照一致性改造；代价是保留明确的历史兼容逻辑。

用户明确选择继续产生 legacy echo，并支持旧 echo-only 历史。每次持久化的 canonical occurrence 都登记一个待配对 echo，按轮次 FIFO 消费；身份集合只控制成功边界幂等，不能因身份重复漏登记随后必有的 echo。未配对的旧 echo 才生成 synthetic 边界，避免吞掉真实的后续压缩。

恢复证据与现状核对：[上下文压缩与用量 #199](https://cnb.cool/jiangshengdev/codex/-/issues/199)。
