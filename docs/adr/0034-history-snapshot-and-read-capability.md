# 历史快照与可替换读取能力分离

历史决定：2026-09-09；响应身份约束确认：2026-08-24。补录日期：2026-09-30。

历史详情按目标任务身份拥有已加载快照，连接替换只更新读取能力，不清除成功内容，也不自动刷新它。读取被断连或能力替换中断时进入失败，连接恢复后由用户手动重试；首次打开新的历史目标仍正常读取，旧请求迟到结果不能串入新目标。

响应只有在请求代次仍有效且实际任务身份匹配时才可成为内容、标题和继续操作的依据。此取舍保留断连时的阅读内容，避免静默读取改变用户所见；代价是分别管理快照身份、当前能力和请求代次。重试始终读取原目标，不能把失败读操作升级为自动激活。

恢复证据与现状核对：[历史列表与只读预览 #194](https://cnb.cool/jiangshengdev/codex/-/issues/194)、[历史继续与定位 #195](https://cnb.cool/jiangshengdev/codex/-/issues/195)。
