# 会话投影统一解释回放事实，下游单向消费

历史决定：2026-09-05。补录日期：2026-09-30。

会话 projection 拥有附着快照索引与回放判定，并产出统一的已接受事件和读模型事实；队列、压缩、transcript 与 threadRuntime 消费同一解释，不各自重判。threadRuntime 只维护会话元信息和用量读模型，不因名称或旧文件位置而成为上游回放规则所有者，也不为内部能力另建没有独立生产入口的公共 feature。

入口的任务、订阅、提交链检查，与快照对内容事实的覆盖判定分别负责不同问题；通过入口检查的通知仍可能是 snapshotDuplicate。后续协作活动细化为[存在与完成分别去重](0018-collaboration-completion-coverage.md)，不能以一个笼统的“已见条目”判断替代两层规则。

此取舍要求下游遵守统一事实契约，换取发送、恢复、压缩与多个视图的一致解释。后来公共 API 中央白名单检查被明确删除，并不撤销这一会话归属决定；未完成的新检查方案也不被补录为已生效约束。

恢复证据与现状核对：[状态归属与公共边界 #203](https://cnb.cool/jiangshengdev/codex/-/issues/203)。
