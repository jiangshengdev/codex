# 统一段落模型并保留消息文本换行

历史决定：2026-09-17。补录日期：2026-09-30。

Composer 的手动换行、粘贴和草稿恢复统一为段落模型，避免相同内容因进入方式不同而具有不同光标行为；段落边界编译为单个换行，保留普通行距及首尾、连续空行。相邻内联 Skill 不因节点边界额外产生换行，复制与发送共用文本遍历，并保留展示文本与提交表示的差别。

旧草稿迁移必须保存原有文本含义，因此 v1 原有双换行通过显式空段保留，接受迁移复杂度而不悄悄改写待发送内容。此决定统一产品输入模型，不声称 Lexical 或 Safari 的底层根因已闭合；历史真实发送验收限定于当时已验证的 Chrome 范围。

恢复证据与现状核对：[文档模型与宿主 #188](https://cnb.cool/jiangshengdev/codex/-/issues/188)。
