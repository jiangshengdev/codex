# 共用输入宿主，保留各自业务生命周期

历史决定：2026-09-18。补录日期：2026-09-30。

新建页和任务页共用 Composer 输入宿主，统一编辑区、附件与 Skill 的 portal、工具栏、焦点及视口行为，避免只复用编辑器节点却继续复制交互外壳。新建流程仍在首次发送时创建任务，独立拥有目录、创建进度、失败重试和首条消息交接；已有任务保留自己的队列与轮次控制。

这一边界以共用复杂交互换取一致性，同时避免要求尚未创建的输入预先具有任务身份。编辑器只读与整个面板禁用分开，输入不可编辑时仍须保留适用的恢复动作；宿主监听随实例挂载和卸载，不由某一业务页面永久占有。

恢复证据与现状核对：[文档模型与宿主 #188](https://cnb.cool/jiangshengdev/codex/-/issues/188)。
