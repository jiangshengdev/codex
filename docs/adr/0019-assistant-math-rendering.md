# 助手公式沿用单一 Markdown 与 KaTeX 链路

历史决定：2026-09-10。补录日期：2026-09-30。

只在助手回答的实时、完成和历史内容中启用数学公式，支持 `\(...\)`、`\[...\]`、`$...$` 与 `$$...$$`。反斜杠形式兼容既有回答，单美元形式按明确选择启用并接受其金额歧义；不把公式能力扩展到用户字面消息、思考摘要、工具输出或编辑器。

公式接入现有 Streamdown/KaTeX 单一链路，通过解析扩展识别反斜杠语法，保护代码、链接和转义边界，不用全局字符串替换改写消息。只合并已识别块公式跨越的渲染块，不合并 transcript chunk 或整个轮次；沿用库默认流式补齐与错误行为，不因启用单美元而启用额外内联补齐，也不放宽内容安全过滤。

后续长公式验证使默认溢出方案改为公式局部横向滚动，保持字号、基线和页面宽度。此取舍兼顾既有文本与长公式阅读，代价是维护受限解析和分块适配；历史静态验收不代表真实流式全程已经验收。

恢复证据与现状核对：[消息富文本与内容操作 #197](https://cnb.cool/jiangshengdev/codex/-/issues/197)。
