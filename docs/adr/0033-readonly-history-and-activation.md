# 历史查看与显式激活分离

历史决定：2026-08-16；路由确认：2026-08-17。补录日期：2026-09-30。

历史列表和详情供只读查看，打开历史 URL 仅读取目标任务快照，不自动 resume、attach 或 send；用户明确选择“继续此任务”后才请求激活。当前任务与历史详情分别使用 `/task/<threadId>` 和 `/history/<threadId>`，分享历史页面也不隐含切换发送对象。

此取舍增加一次显式继续操作，换取查看资料与改变执行上下文之间的清楚边界。有效空历史仍可继续，移除界面上的“只读”说明或返回按钮不改变只读语义。这里限定 GUI 不主动执行上述激活命令，不承诺服务端读取在所有情况下没有任何落盘副作用。

历史列表的目录范围与详情的目标任务身份是不同概念。2026-09-30 裁决保留[原始任务固定基准](0053-original-task-page-baseline.md)：历史列表使用原始任务目录，不随当前查看任务改变；历史详情仍读取被选择的目标任务。这记录已确认语义，不表示实现差异已经修复。

恢复证据与现状核对：[历史列表与只读预览 #194](https://cnb.cool/jiangshengdev/codex/-/issues/194)。
