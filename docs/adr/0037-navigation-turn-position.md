# 轮次末尾通过严格 URL 参数进行一次导航定位

历史决定：2026-09-11。补录日期：2026-09-30。

当前与历史任务 URL 使用 `?turnId=<turnId>&position=end` 表达轮次末尾定位。选择 query 以使用路由器的解析、校验与类型能力，避免 hash 自动滚动；接受参数会发送给服务端、可能进入日志的代价。缺项、空值、重复值或未知 position 进入错误页，不补默认值。

每次导航，包括同页参数变化、前进后退及刷新，重新执行一次定位；普通渲染和流式更新不重复触发。目标先选择所属上下文展示页，再将轮次末端对齐可用视口底部；找不到则转到最新内容并给临时提示，不新增复制链接入口。

定位消费已经加载的历史和既有展示分页，不引入延迟加载契约；同轮无正文时使用其实际展示边界，不把它误判为目标缺失。此取舍使分享和刷新保留明确意图，代价是严格的参数验证与导航访问身份管理。

恢复证据与现状核对：[历史继续、分叉与定位 #195](https://cnb.cool/jiangshengdev/codex/-/issues/195)。
