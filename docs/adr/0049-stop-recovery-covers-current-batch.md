# 本地停止后的继续只覆盖当次恢复批次

历史决定：2026-08-19；晚到确认修订：2026-09-10。补录日期：2026-09-30。

本 GUI 主动停止后，未进入正式消息的引导保留为人工恢复，不自动启动后续轮次；非本地终止则按原补交规则处理。本地归属由本 GUI 的停止 owner 证明，不能从没有相应原因的投影终态猜测。

一次“继续发送”只覆盖当次确定的恢复批次。旧引导后来才收到 accepted 且尚未提交时，再次进入人工恢复，需要新的继续操作；已提交且被消费的内容不重建，未知或目标不匹配也不因裸终态自动重发。此取舍保留停止意图，接受晚到确认需要再次操作的代价，不把此前操作扩展为对未来内容的预先许可。

旧持久记录缺失停止归属时，已接收但未提交的内容保守迁入人工恢复，未知结果继续保留而不发送。恢复归属随持久化保存，不能以迁移猜测本地或非本地停止。

恢复证据与现状核对：[引导输入与发送调度 #184](https://cnb.cool/jiangshengdev/codex/-/issues/184)、[页面会话恢复](0038-page-session-manual-restoration.md)、[未知交付](0042-unknown-delivery-is-not-rejection.md)。
