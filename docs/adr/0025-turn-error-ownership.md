# 错误保留轮次归属，不伪装成消息

历史决定：2026-08-15。补录日期：2026-09-30。

失败详情属于轮次，独立于顶部状态显示在该轮末尾，不作为助手消息、新轮次或某个中间条目插入。协议没有提供条目级位置时不猜测精确位置；只有错误而没有消息的轮次仍须可见。

此取舍保持实时、历史与投影中的真实归属，代价是无法指出失败发生在轮内哪个条目。完整显示既有错误 message，不扩大为展示全部未来协议字段；后来的按需诊断面板不把这些轮次错误全部强制迁入弹窗。

恢复证据与现状核对：[错误与诊断反馈 #200](https://cnb.cool/jiangshengdev/codex/-/issues/200)。
