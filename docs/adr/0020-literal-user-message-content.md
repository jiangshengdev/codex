# 用户消息保留字面语义并统一内容入口

历史决定：2026-09-20。补录日期：2026-09-30。

所有已发送用户消息使用同一正文入口，附件作为内容差异，不再分裂为纯文本与附件两套渲染路径。用户的 Markdown、HTML、空白和换行仍按字面显示，文本与附件保持原顺序；统一入口修正了此前只调整混排消息而遗漏纯文本消息的问题。

有附件标记时按协议的 UTF-8 字节范围还原混排，没有标记时直接保留原串。实时与历史使用同一投影合同，保留既有块更新边界，并从原始数据重建而非维护旧表示的兼容分支。此取舍减少重复入口造成的行为漂移，接受角色专属结构化内容契约的成本，不把“统一”解释为将用户输入转为 Markdown。

恢复证据与现状核对：[消息富文本与内容操作 #197](https://cnb.cool/jiangshengdev/codex/-/issues/197)。
