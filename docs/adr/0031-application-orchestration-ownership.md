# 应用编排与展示适配分离，保留原有权威状态

历史决定：2026-08-25；失效保留修订：2026-09-08、2026-09-09。补录日期：2026-09-30。

待发送管理与 Send/Guide/Recover/Stop 的应用编排放入无 DOM 模块，隐藏占位、刷新、结果分类与提交临界区；React 承担渲染、可见生命周期、文案和焦点执行，Lexical/DOM/ARIA 保留真实平台适配。队列与 coordinator 拥有投递事务，活动会话拥有能力与发布门禁，编辑器拥有草稿，不另建中央 Composer 状态机或 Redux 镜像。

管理视图从原队列按需取得计数、分页与全文，不在 React 复制完整队列。只在接受提交后清除仍对应同次捕获的输入；拒绝时保留草稿，旧回调不能清除新的输入或发布过期状态。

后续明确修订将真正失效后的写回权限与内容保留分开，断连可保留任务和未保存修改，不能恢复早期一律关闭编辑的规则。此取舍以显式能力和生命周期边界换取单一权威来源，接受模块之间传递事实与身份的成本；共享页面展示也不意味着合并新建、活动与只读历史的业务 owner。
