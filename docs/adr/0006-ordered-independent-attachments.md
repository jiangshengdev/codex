# 附件独立上传，混排输入等待全部就绪

历史决定：2026-09-17；保序再确认：2026-09-18。补录日期：2026-09-30。

选取、粘贴或拖入附件时立即在正文中插入原子内容，保存文字与附件的原始顺序；多文件各自上传、重试和移除。发送等待所有剩余附件上传就绪，允许纯附件输入，避免以部分上传结果悄悄改变用户提交的内容。代价是一个未完成或失败的附件也会阻止整条输入发送，用户需重试或显式移除。

附件移除后，迟到的上传结果不能使其复活；草稿恢复保留附件身份与顺序，但不自动续传未完成上传。正文顺序贯穿草稿、提交和历史回显；发送协议可按类型组织图片输入，并用正文位置元数据保留混排语义，不要求协议数组逐项交错排列。
