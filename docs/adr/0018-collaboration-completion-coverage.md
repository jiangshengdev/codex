# 协作活动的存在与终态覆盖分别去重

历史决定：2026-09-09。补录日期：2026-09-30。

中途订阅时，快照中的 wait/resumeAgent 进行中活动立即呈现，后续完成更新同一记录。快照已经见过该记录，只能证明开始已覆盖，不能把尚未见过的完成结果当作重复；已有终态和真正重复通知继续去重，并保留成功、失败或中断的真实结果。

此取舍同时提供即时可见性与完整终态，代价是分别记录活动存在和完成覆盖，不能用单一“见过 item”集合处理全部事件。同一次工具调用原位完成，与子代理独立 Completed 历史动作追加是不同事实，不相互替代。

恢复证据与现状核对：[协作活动与子代理关系 #198](https://cnb.cool/jiangshengdev/codex/-/issues/198)。
