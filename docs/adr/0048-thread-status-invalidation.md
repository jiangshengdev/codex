# 无序任务状态通知仅触发权威重读

历史决定：2026-09-03。补录日期：2026-09-30。

任务与轮次是不同状态层，轮次结束不能推出整个任务空闲。`thread/status/changed` 没有 revision 且异步到达，因此只使当前状态失效，随后单飞 `thread/read(includeTurns:false)` 获取权威状态；读取期间再收到通知则标记待重读，不按最后到达通知覆盖。

读取失败表示状态未知，不伪装为 systemError；实例和代次隔离旧结果，避免污染新会话。此取舍增加读取往返，换取无序通知下状态最终收敛；缺少这个背景时删除额外读取会重新引入状态回退竞态。

恢复证据与现状核对：[任务身份与活动会话生命周期 #190](https://cnb.cool/jiangshengdev/codex/-/issues/190)。
