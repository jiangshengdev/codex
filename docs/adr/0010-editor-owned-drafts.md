# 编辑器拥有草稿，发送契约独立归协议派生

历史决定：2026-09-05。补录日期：2026-09-30。

编辑器拥有草稿的捕获、恢复、内部格式与版本迁移；队列保留不透明草稿，在恢复时交回编辑器，不定义或改写编辑器内部状态。发送数据由独立公共输入契约从协议类型派生，避免编辑器与队列互相依赖内部定义，或维护第二份手写协议形状。

草稿与发送数据必须来自同一次捕获，提交完成不能误清之后的新输入，恢复失败不能丢弃原消息，待发消息在独立编辑器中恢复。接受显式公共契约的成本，以免排队和持久化成为第二个编辑器状态所有者；持久化位置与恢复时机另由页面会话恢复合同规定。

恢复证据与现状核对：[文档模型与宿主 #188](https://cnb.cool/jiangshengdev/codex/-/issues/188)。
