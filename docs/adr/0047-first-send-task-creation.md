# 新建输入首次发送才创建，并保留创建与交接结果

历史决定：2026-09-06 至 2026-09-07。补录日期：2026-09-30。

打开新建页只持有页面内存草稿，首次发送才创建空白任务，使用目录生效的默认配置、不继承对话。草稿建立后固定其目录；取得任务身份后保留并在重试时复用，直到队列接受首条输入才释放草稿。

导航或连接变化后的迟到结果保留身份与输入，不抢页面或自动发送；断连保留可见内容但禁止编辑发送，重连不自动提交。创建结果未知时人工重试可能留下额外空任务，而交接未知不能当作明确失败重新发送。

此取舍避免仅浏览页面就创建任务，代价是分别管理创建、激活和首条交接。2026-09-30 裁决保留后续确认的[原始任务固定基准](0053-original-task-page-baseline.md)：新草稿以原始任务目录及该目录生效的默认配置为依据，不随当前查看任务变化；这不扩大为跨刷新草稿持久化。

恢复证据与现状核对：[任务身份与活动会话生命周期 #190](https://cnb.cool/jiangshengdev/codex/-/issues/190)。
