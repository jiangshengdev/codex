# 轮次耗时采用包含等待的权威整轮口径

历史决定：2026-09-12。补录日期：2026-09-30。

GUI 轮次耗时表示运行时开始到结束的完整经过时间，包含等待审批或用户回答。实时显示依据权威开始时间，终态采用后端最终耗时，以统一实时、历史与重连后的含义；不照搬 TUI 实时扣除等待而最终耗时包含等待的不同口径。

开始、结束或耗时数据缺失时省略对应显示，不从点击发送、组件挂载或猜测的等待区间补造。此取舍保留统一的经过时间定义，放弃把它解释为纯计算时间；若将来需要扣除等待，必须有相应的权威时间数据，不能只暂停本地显示时钟。

恢复证据与现状核对：[消息与轮次投影 #196](https://cnb.cool/jiangshengdev/codex/-/issues/196)。
