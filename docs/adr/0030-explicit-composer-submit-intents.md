# GUI 保留显式发送与引导意图，不按状态偷换动作

历史决定：2026-09-29。补录日期：2026-09-30。

GUI 的普通 Enter 发送与 Command/Ctrl+Enter 引导保持不同意图；新会话或空闲任务中引导不可用时，组合键不提交并保留草稿，不改为普通发送。用户明确选择此语义，而非照搬 TUI 根据运行状态在同一提交动作中分流。

编辑器必须显式获知当前允许的意图，未支持的提交键被消费但不调用提交；新建页和已有任务复用发送展示，同时保留创建交接与已存在队列的不同业务生命周期。运行轮次中，空输入的引导快捷键仍可提升普通队首；这不等于空输入时引导按钮也可用，待发编辑器的保存行为也不因此被取消。

聚焦快捷键只使用当前可编辑输入能力，不为了聚焦导航、创建或恢复；调用时仍核对挂载、身份与编辑能力。此取舍使相同操作意图可预测，代价是能力不足时没有提交副作用，而不是提供看似便利但可能误发的替代动作。

恢复证据与现状核对：[导航、路由与快捷键 #201](https://cnb.cool/jiangshengdev/codex/-/issues/201)、[普通输入与引导分离](0001-separate-ordinary-and-guidance.md)。
