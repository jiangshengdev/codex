# HeroUI 拥有全局视觉语义，富文本仅在局部被覆盖

历史决定：2026-09-11。补录日期：2026-09-30。

HeroUI 拥有应用全局主题及工具类语义；Streamdown 文档与其 body portal 在局部选择器边界直接消费 Hero token，不为富文本重定义全局主题工具类。两者同名 muted 的前景与背景含义不同，全局映射即使未改原变量，也会污染其他控件的视觉契约。

用户明确否定并撤回早期全局映射，要求用 Hero 样式覆盖富文本而非反向覆盖应用。此取舍增加文档和 portal 选择器维护，换取全局组件语义稳定；与[富文本操作 owner](0021-richtext-content-and-actions.md)相互配合，但不要求重写库的内容处理。

后续源码符合局部覆盖方向；原会话末尾重新提出的完整实施计划未再次确认，不能据当前代码倒填那次实施或验收完成。这里恢复的是用户已直接确定的主题责任边界。

恢复证据与现状核对：[可访问布局与控件约定 #202](https://cnb.cool/jiangshengdev/codex/-/issues/202)。
