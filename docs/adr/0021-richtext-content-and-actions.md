# 富文本内容使用公开库能力，操作交互由 HeroUI 承担

历史决定：2026-09-12。补录日期：2026-09-30。

正文、高亮、数学及表格序列化沿用 Streamdown 公开能力，HeroUI 承担复制按钮、菜单与全屏弹层的交互和焦点。通过公开替换边界修复实际操作缺口，不修改第三方依赖、私有 deep import 或维护手写下载映射；代码与普通、全屏表格的下载均已明确移除，替代早期按语言选择扩展名的方案。

代码复制与表格复制分别检查所需剪贴板能力。表格将所选格式的纯文本和 HTML 同次写入，失败明确可见并可重试，不静默降为纯文本。静态表从顶部阅读，流式表可以贴底跟随，但读者上滚后不抢回位置。

此取舍保留成熟内容处理，同时承担应用操作层的能力检测与可访问交互，避免为保留下载入口扩展成第三方维护义务。样式覆盖限定在富文本及其弹层范围，不反向改写应用全局主题。

恢复证据与现状核对：[消息富文本与内容操作 #197](https://cnb.cool/jiangshengdev/codex/-/issues/197)。
