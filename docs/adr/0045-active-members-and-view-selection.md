# 活动集合与当前查看选择分离

历史决定：2026-09-06 至 2026-09-07。补录日期：2026-09-30。

GUI 可以驻留多个独立任务，一次查看其中一项；切换查看不终止后台成员的执行、队列或订阅，后台异常只归该成员，完成后仍保留驻留关系。显式移出不是停止任务或删除持久历史，执行、排队或恢复未收敛时拒绝移出。

查看不清除失败，也不自动重试，激活和恢复由显式操作承担。移除当前项成功且用户仍在该任务页时进入历史列表；移除后台项、期间已切页或移除失败都不抢导航，替代早期进入该项历史详情的方案。

此取舍支持后台执行和独立错误边界，代价是管理成员生命周期、通知和恢复，比将切页等同销毁更复杂。2026-09-30 裁决保留原始任务不可移出的已确认约束，详见[原始任务固定基准](0053-original-task-page-baseline.md)；其他成员继续适用上述移出规则。

恢复证据与现状核对：[任务身份与活动会话生命周期 #190](https://cnb.cool/jiangshengdev/codex/-/issues/190)。
