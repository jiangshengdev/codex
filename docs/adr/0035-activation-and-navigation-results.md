# 激活结果与页面导航结果分开恢复

历史决定：2026-08-24；历史继续呈现修订：2026-09-04。补录日期：2026-09-30。

历史继续先由活动会话 owner 返回权威激活结果，页面只在结果允许时导航到其明确任务身份。提交前失败与提交后能力不可用分开，错误保留在历史操作区；旧资源清理失败不回滚已经成功的激活，而是单独保留警告。

激活已成功但导航失败时保留已就绪身份，重试只导航，不再次执行激活副作用；能力替换或页面身份变化仍须隔离迟到结果。此取舍增加结果分类和恢复状态，换取不因页面动作失败重复执行已经完成的业务操作。用户查看历史与显式继续的边界见[只读历史](0033-readonly-history-and-activation.md)。

恢复证据与现状核对：[历史继续、分叉与定位 #195](https://cnb.cool/jiangshengdev/codex/-/issues/195)。
