# 原始任务作为页面固定基准，与当前查看任务分离

历史分项确认：2026-09-07。保留决定的裁决与补录日期：2026-09-30。

从 TUI 启动 GUI 时确定的原始任务，是页面的固定身份与目录基准。菜单入口固定指向它，活动列表的圆点仍表示当前查看任务；切换任务、页面刷新均不重定原始身份，只有重新通过 TUI 启动链接进入时才重新确定。原始任务始终保留在活动集合中，不允许移出。

历史列表使用原始任务目录，后续新建也使用该目录及其生效的默认配置，创建空白任务、不继承对话；这替代先前随当前或最近查看任务取目录的决定。固定基准不改变其他任务自身的发送、队列、设置或历史详情归属。

这一取舍保证页面基准不随浏览行为漂移，代价是分别维护原始任务和查看选择的生命周期，并让历史与新建的目录独立于正在查看的任务。原始任务暂时加载失败但已有目录时是否继续开放历史与新建，当时没有得到回答，本次仍未确认，不推导默认行为。

2026-09-30 的裁决保留上述已确认语义；代码中的可变目录和缺少原始任务保护记录为实现差异，不能用未实施撤销决定，也不表示本轮已实现这些行为。
