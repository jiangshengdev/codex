# 页面会话内保存工作，刷新后人工继续实际待处理项

历史决定：2026-09-06；人工恢复及空记录修订：2026-09-07。补录日期：2026-09-30。

已激活任务的队列与底部草稿保存在页面会话范围，使用 sessionStorage，不新增跨关闭共享元数据或跨标签全局去重。接受浏览器原生恢复、复制标签页可能保留存储副本的边界，但不将其承诺为产品跨关闭持久化。新建页草稿仅在内存中保留，未保存的待发送编辑不跨刷新恢复，队列保留最后保存版本。

后续选择人工继续替代早期自动恢复：初始化核对后，真实队列或其他待处理工作保持恢复暂停；用户明确继续也不能解除未知交付或其他独立屏障。空记录或仅有底部草稿时不增加暂停，草稿不自动发送。

此取舍避免在没有跨页协调和服务端幂等保证时自动执行恢复副本，代价是刷新后需要人工检查并继续。多活动成员分别保存其工作，存储不接管业务恢复权限；连接重建与页面刷新恢复是不同边界。

恢复证据与现状核对：[持久化与刷新恢复 #191](https://cnb.cool/jiangshengdev/codex/-/issues/191)。

2026-09-30 裁决同时保留[原始任务固定基准](0053-original-task-page-baseline.md)的刷新身份约束：刷新后恢复原始任务身份，不能用当前查看任务重定；只有重新通过 TUI 启动链接进入才重新确定。这是独立于队列与草稿保存的身份要求，不改变上述人工继续条件，也不承诺新建草稿或未保存编辑跨刷新保留。
