# 原文件按主机路径交付，模型消费独立

历史决定：2026-09-17；修订：2026-09-20。补录日期：2026-09-30。

附件上传保存原始字节到 CLI/Core 主机并返回路径，文件解析和必要转码由模型按需使用已有工具完成，产品不提供转码承诺。普通文件以路径交付；支持的图片另有结构化图片输入。不支持的图片格式同普通文件处理，不额外警告或显示图片预览。这替代了早期将不支持格式判为失败并阻塞发送的行为；曾提出的公共协议/Core 图片拒绝扩展已被明确撤回。

成功文件保留在系统临时目录，CLI 退出不主动删除，也不承诺永久存储。单文件限制为不超过 50 MiB 原始字节；失败由用户手动整文件重传，不承诺断点续传、自动重试或幂等去重。此取舍使上传边界保持为原文件交付，代价是消费能力由模型和工具决定，响应丢失后的重试可能留下多个成功文件。

恢复证据与现状核对：[附件上传与预览 #189](https://cnb.cool/jiangshengdev/codex/-/issues/189)。
