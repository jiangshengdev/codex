# GUI host 通用托管页面，前端独占业务路由判断

历史决定：2026-09-28。补录日期：2026-09-30。

生产 GUI host 对符合页面导航条件的请求返回 SPA 入口，非法任务地址与未知页面由前端显示 NotFound；删除 Rust 逐页注册及重复业务 ID 校验。API、WebSocket、上传、文件预览、静态资源和安全边界仍由 host 负责，缺失资源不能伪装成页面。

选择 HTTP 成功交付页面后由前端判定业务路由，接受它与服务端直接返回业务 404 的差异，以避免两端路由枚举漂移。启动任务路径仍可共享，纯前端页面不要求逐页修改 Rust。

已接受的边界是：缺少 `Sec-Fetch-Dest` 时，末段含点按资源启发处理，即使请求接受 HTML，也可能返回 404。用户明确选择记录并关闭该边界；不能借恢复文档把它改写成新的待修缺陷。开发服务器可刷新不证明生产 host 已支持相同路径，二者须分开核验。

恢复证据与现状核对：[导航、路由与快捷键 #201](https://cnb.cool/jiangshengdev/codex/-/issues/201)。
