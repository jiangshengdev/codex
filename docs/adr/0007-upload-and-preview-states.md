# 上传状态与图片预览状态独立

历史决定：2026-09-20。补录日期：2026-09-30。

上传成功即满足附件侧发送条件，无需等待图片预览成功。预览读取或解码失败只影响展示，不回滚上传，也不以重新上传来修复预览；读取失败可以单独重试，解码失败不自动重试。这将发送资格交给上传结果，避免浏览器展示故障阻塞已成功交付的文件，代价是界面需要分别表达上传和预览状态。

两种重试保留不同反馈：上传重试进入上传中并隐藏旧上传失败详情；预览重试保留上一失败和忙碌反馈直到成功。两者不能合成同一失败状态或同一重试动作。

恢复证据与现状核对：[附件上传与预览 #189](https://cnb.cool/jiangshengdev/codex/-/issues/189)。
