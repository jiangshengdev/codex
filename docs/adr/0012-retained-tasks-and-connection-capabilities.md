# 断连保留任务数据，独立恢复每个成员的能力

历史决定：2026-09-09。补录日期：2026-09-30。

连接关闭撤销命令能力，但保留已打开任务的对话、队列、草稿和编辑身份，并冻结操作。连接与任务数据分开拥有，避免销毁后重建丢失尚未保存的编辑和发送状态；这替代早期断连即 dispose 的方案，但不提供离线编辑或发送。

新连接恢复所有已打开成员，而非只恢复当前页或等待切换时按需恢复。成员独立取得订阅和权威快照，单个失败可单独重试，不使其他成员失效；恢复期间依据当前路由与编辑归属，而非启动时捕获的页面。旧连接读取结果不能发布，已经发出的请求仍按原交付身份结算，不能丢弃可能已经执行的结果。

代价是共享连接就绪与各成员就绪必须分别管理和展示，并维护可撤销、可替换的单一命令能力。此决定适用于连接中断后的内存保留，不扩大页面关闭后的持久化范围；特定浏览器生命周期中的自动重连也不等于未知请求自动重发。

恢复证据与现状核对：[连接与同步恢复 #192](https://cnb.cool/jiangshengdev/codex/-/issues/192)。
