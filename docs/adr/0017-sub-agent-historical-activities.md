# 子代理展示历史活动，身份与名称分离

历史决定：2026-08-18；完成活动修订：2026-08-28；合法名称修订：2026-09-08。补录日期：2026-09-30。

GUI 增强转录中的协作活动，不建立独立实时代理面板，也不回写过去动作来表示当前状态。代理以线程身份识别，以任务路径产生可读名称，不用昵称、角色或名称作为身份；标签只读，不隐含打开子线程的行为。相邻同动作可以聚合展示，但保留原事件顺序、动作边界和真实省略计数。

成功完成作为独立 Completed 活动追加，不将 Started 改写为 Completed。此取舍保留历史事实，避免引入跨事件同步的第二个实时状态所有者；代价是读者须区分“曾启动”与“现在仍运行”。合法的全下划线任务名原样保留，格式化不能使合法名称消失。

历史选择要求同一转录内重名时补充最短父路径。补录时核对发现，当前实现只在连续同动作组内消歧，跨组重名仍有差异；本次记录保留原决定和实现缺口，不将要求收窄为组内，也不在文档恢复任务中修代码。

恢复证据与现状核对：[协作活动与子代理关系 #198](https://cnb.cool/jiangshengdev/codex/-/issues/198)。
