# 写回有效性与未保存内容存续分开

历史决定：2026-09-08。补录日期：2026-09-30。

长期编辑能力受原 owner 及其有效生命周期约束，普通聊天回复带来的展示 revision 变化不撤销编辑。目标、连接或所属会话真正失效时拒绝写回并清理旧占位，但保留已捕获的修改，供用户选取复制或明确丢弃，不覆盖底部输入草稿，也不随原输入区卸载而直接丢失。

关闭有未保存修改的编辑前确认丢弃；保留内容不等于仍有发送权限，也不承诺浏览器刷新后恢复该编辑。恢复期间仍有效的编辑可以保存，但不得因此提前发送。Drawer 退出与页面切换须维持必要内容和有效焦点目标。

此取舍增加保留内容宿主与有效性边界，避免把正常展示更新误当失效，也避免以失去保存权限为由丢弃用户输入。2026-09-30 裁决维持对失效保留内容专用 Copy 按钮的否定：保留内容可选取、手动复制，不将其扩成专用按钮需求。后续剪贴板测试及技术收尾不构成对按钮的重新认可，既有按钮实现另记为差异；此边界不否定其他独立确认的代码块或表格复制功能。

恢复证据与现状核对：[待发送输入编辑与排序 #185](https://cnb.cool/jiangshengdev/codex/-/issues/185)。
