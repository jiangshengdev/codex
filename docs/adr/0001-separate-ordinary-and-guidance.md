# 普通排队与当轮引导分别管理

历史决定：2026-08-19。补录日期：2026-09-30。

普通输入等待后续轮次，引导输入面向当前运行中的轮次；两者分别管理，允许显式引导越过普通输入队列，避免把用户主动插队的意图变成所有输入的全局先进先出。
从普通输入队列提升为引导时，只取当前队首；被明确判定为当前轮次不可引导的输入保留优先意图，在当前轮次结束且允许继续发送时按原顺序合并为新轮次，先于普通输入发送。
这里不限定内部容器数量；2026-08-23 确认的同队列手动排序可以改变当前排列，但不合并普通排队与引导的语义。

恢复证据与现状核对：[领域概念恢复验收 #183](https://cnb.cool/jiangshengdev/codex/-/issues/183)。
