# 反馈位置按影响范围确定，共享位置不接管状态

历史决定：2026-09-25。补录日期：2026-09-30。

具体消息、上传、草稿、输入、弹窗、列表追加加载及底部继续任务的失败保持原位；整个主体不可用时由错误替代主体；影响整页或跨任务管理且主体仍在的提示，进入共享浮动区域。分叉创建与打开属于跨任务操作，不能仅按触发按钮位于消息内就判为消息错误。

共享区域只统一展示目的地，不转移状态、请求或恢复动作的 owner。当前选择完整展开、限高且可滚动，替代已经明确撤回的首条加计数折叠方案；这不构成永久禁止未来折叠的规则。

此取舍保留故障与操作的真实归属，同时避免页面级提示散落和遮蔽主体；代价是必须区分影响范围，不能以单一 toast 或统一大面板承载所有错误。

恢复证据与现状核对：[错误与诊断反馈 #200](https://cnb.cool/jiangshengdev/codex/-/issues/200)。
