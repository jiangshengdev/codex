# 思考摘要仅在完成后形成权威记录

历史决定：2026-08-14；呈现修订：2026-08-15。补录日期：2026-09-30。

GUI 仅展示面向用户的 reasoning summary，与 commentary 和原始 reasoning 分开，不使用原始内容作为摘要 fallback。每个 reasoning item 保留一个记录身份，多段摘要按原顺序组合；生成期间只展示临时摘要标题，完成后采用权威完整摘要，避免不断用半截 Markdown 扩充正式记录。

中断、失败或投影失效时丢弃未完成摘要，接受不保留半成品的代价，避免将可能缺失增量的内容伪装成完整历史。摘要、过程说明及可见活动保留事件顺序，最终回答出现后作为默认折叠的中间更新。后来由 TUI 圆点改为 Card 的外观修订不改变该生命周期。

恢复证据与现状核对：[消息与轮次投影 #196](https://cnb.cool/jiangshengdev/codex/-/issues/196)。
