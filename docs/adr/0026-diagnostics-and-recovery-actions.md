# 诊断属于内容，恢复属于业务动作

历史决定：2026-09-05 至 2026-09-07；后续统一：2026-09-09、2026-09-19。补录日期：2026-09-30。

适用反馈保留原位摘要与查看入口，完整诊断由 Modal 正文单独滚动，背景锁滚，关闭后恢复入口焦点。此方案替代内联 Disclosure 的内外双滚动实验，避免额外 wheel 补偿；不声称原浏览器底层根因已解决。

诊断入口跟随说明内容，恢复动作按业务可用性单独呈现；窄布局中动作位于完整内容之后，没有恢复动作时也不让诊断顶替它。保留不同故障载体，不把所有纯文本错误升级为统一大面板。

共享展示只负责内容、布局、滚动与焦点，错误状态、严重性、重试条件和成功判据仍归各业务。以明确职责换取跨页面复用，接受多个业务 owner 保留各自恢复语义的成本，避免万能错误组件接管业务状态。

恢复证据与现状核对：[错误与诊断反馈 #200](https://cnb.cool/jiangshengdev/codex/-/issues/200)。
