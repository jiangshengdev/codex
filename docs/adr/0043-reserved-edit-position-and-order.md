# 编辑保留原队列位置，排序改变真实发送顺序

历史决定：2026-08-23。补录日期：2026-09-30。

待发送条目在独立编辑会话中恢复成功后，原队列保留占位；恢复失败则队列和编辑器均不变。占位前的条目可以发送，后序不能越过；保存替换内容但保留消息身份、队列类别和顺序，取消恢复原内容。此方案替代直接取走条目再追加，因为后续条目一旦先发出，取消已无法恢复原顺序。

同队列排序直接修改权威 owner 的真实发送顺序，引导在拒绝或恢复后仍保留修改后的顺序，不只重排展示数组；跨队列移动不在该能力内。可管理性按真实队列及编辑、恢复能力判断，不笼统禁止全部恢复期间排序。

代价是编辑占位阻止后续条目即时发送，并要求发送、恢复和删除都识别该归属；换取取消可恢复、保存不隐式重排，以及显示顺序与实际执行一致。底部输入草稿仍独立存在。

恢复证据与现状核对：[待发送输入编辑与排序 #185](https://cnb.cool/jiangshengdev/codex/-/issues/185)。
