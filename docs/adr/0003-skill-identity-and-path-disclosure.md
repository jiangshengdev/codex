# Skill 精确身份与界面路径披露分离

历史决定：2026-08-29；已选项详情扩展：2026-08-30。补录日期：2026-09-30。

Skill 始终保留精确路径身份，但界面只在消歧或失效诊断需要时披露最短可区分父路径。canonical 名称相同且路径不同即视为碰撞，不能因显示名称不同而隐藏消歧信息，也不能按名称丢弃合法候选。这样保留准确选择能力，同时减少路径噪声和不必要的目录信息披露，无需新增协议来源字段。

这取代了早期已确认的底部完整路径详情：随活动候选切换的底部区域会闪烁，后来改为对应候选行内按需显示。已选项详情只消费候选目录元数据，不为展示详情读取完整 Skill 文件；显示、复制和执行身份各自保持边界。

恢复证据与现状核对：[Skill 候选与结构化提交 #186](https://cnb.cool/jiangshengdev/codex/-/issues/186)。
