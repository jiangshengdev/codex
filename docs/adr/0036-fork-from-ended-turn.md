# 从已显示的结束轮次创建带历史的新任务

历史决定：2026-09-11。补录日期：2026-09-30。

当前与历史页面可从既有、已显示且已结束轮次的末尾分叉，包含成功、失败和中断，不为不可见空轮次新增入口；来源任务仍运行时也可分叉更早的结束轮次。新任务包含截至该位置的聊天历史，沿用来源工作目录及后端当前配置，不恢复分叉点模型，不复制草稿、队列或页面状态，也不创建文件隔离 worktree。

成功后打开新任务；已知新任务身份但打开失败时复用该身份恢复，不重新创建。创建结果未知时不自动重发，先查看历史；用户再次从原入口创建可能得到重复任务。此取舍避免在缺少创建幂等保证时静默重复副作用，代价是未知结果无法自动消除。

同一来源还确认过直接父来源入口与继承/新增分界，但随后明确暂停、先实施分叉操作。来源展示属于已确认但暂停未实施的历史意图，当前不宣称具备该能力；父任务后来变化也不能用最后共同轮次猜测原分叉边界。

恢复证据与现状核对：[历史继续、分叉与定位 #195](https://cnb.cool/jiangshengdev/codex/-/issues/195)。
