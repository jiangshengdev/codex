# 当前上下文用量由投影基线与绝对更新提供

历史决定：2026-08-18；入口可用性后续修订见来源票。补录日期：2026-09-30。

用量通过投影快照基线及同一订阅、提交链上的绝对更新传递，避免普通通知旁路缺少初始值和顺序保证。GUI 保存原始量，以 `last.totalTokens / modelContextWindow` 表达当前上下文已用比例，不使用累计 total、不扣 TUI baseline、不从模型名称猜容量，也不在客户端累计增量。

用量更新不改变消息、轮次、队列或滚动位置。比例仅作中性展示，不推导自动压缩阈值或压缩进度；后续明确选择在百分比不可用时隐藏整个用量入口，替代早期未知用量仍能从该入口压缩的方案。可用时手动压缩没有额外使用率门槛。

此取舍增加协议与投影基线的责任，换取首次打开、实时变化、压缩后及重连时一致的当前用量含义。

恢复证据与现状核对：[上下文压缩与用量 #199](https://cnb.cool/jiangshengdev/codex/-/issues/199)。
