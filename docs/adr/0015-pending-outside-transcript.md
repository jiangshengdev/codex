# 待处理输入在运行时确认前保留于正式记录之外

历史决定：2026-08-19。补录日期：2026-09-30。

请求已发出但尚未由运行时正式确认的用户输入，在 transcript 外展示待处理预览；正式用户消息由运行时投影事实建立。这样用户可以核对待处理内容，而不会把网络结果未知或尚未正式提交的请求误认为已经写入对话。

代价是正式记录出现晚于本地提交；选择独立待处理展示，避免乐观插入、失败撤回和额外去重形成第二条消息历史路径。引导已被接收也不等于已经形成正式消息，后续恢复仍按其交付与提交事实处理。

恢复证据与现状核对：[消息与轮次投影 #196](https://cnb.cool/jiangshengdev/codex/-/issues/196)、[普通输入与引导 #184](https://cnb.cool/jiangshengdev/codex/-/issues/184)。
