# 显式 Skill 身份随输入文档保存

历史决定：2026-08-19。补录日期：2026-09-30。

同名 Skill 可以指向不同文件，用户又能移动、删除和撤销输入，因此不采用纯文本名称或字符位置旁路映射来维持选择。显式选择的节点携带 canonical `name` 与准确 `path`，内部编辑、草稿恢复和复制保留该身份；提交从文档编译结构化输入，已排队内容不再根据最新目录按名称重新绑定。代价是维护结构化文档及其转换边界，换取同名选择在编辑和发送全过程中不失真。

显示名称与执行身份分开：对外普通文本使用 canonical 名称，不因显示名或来源译文变化改变目标；对外复制不附带内部 Skill 路径。只有完整成功目录才能证明已选项失效，失效状态由当前证据派生，不写回作者输入或撤销历史。

恢复证据与现状核对：[Skill 候选与结构化提交 #186](https://cnb.cool/jiangshengdev/codex/-/issues/186)。
