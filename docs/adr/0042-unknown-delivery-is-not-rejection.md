# 未知交付保留并阻塞，不通过自动重发恢复

历史决定：2026-09-06；清理与迁移细化：2026-09-08、2026-09-10。补录日期：2026-09-30。

在没有幂等接收查询契约的范围内，无法确认的输入保留为未知交付，阻塞对应任务的后续发送，不影响其他任务。超时、刷新、历史暂时没有消息、更换连接或人工继续恢复队列，都不足以证明未接收，不能据此自动重发。

有精确关联的权威提交事实时按既有核对收敛；否则用户可以移除本地记录，但该动作不撤回服务端消息。请求关联身份与本地消息身份分开，避免本地身份复用误匹配旧请求；这仍不构成服务端幂等保证。

用户选择前端保留并人工处理，放弃扩展后端查询与幂等后自动恢复，代价是某些未知状态需持续阻塞。移除合并记录须完整释放归属，遵守[先保存后发布效果](0039-persist-before-publishing-effects.md)，不能清掉其他未知或恢复屏障。

恢复证据与现状核对：[发送结果未知 #193](https://cnb.cool/jiangshengdev/codex/-/issues/193)。
