# Triage 标签

| 标准角色 | CNB 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 需要维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 需求已完整明确，可交由代理实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予处理 |

skill 提及 triage 状态时，使用这些完全一致的标签字符串。
`bug` 和 `enhancement` 等分类标签与这些状态标签相互独立。

本文件定义映射，不会创建远程标签。
