# Triage labels

| Canonical role | CNB label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Requires maintainer evaluation |
| needs-info | needs-info | Waiting for additional information |
| ready-for-agent | ready-for-agent | Fully specified and ready for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Use these exact label strings when a skill refers to a triage state.
Category labels such as `bug` and `enhancement` are separate from these states.

This file defines the mapping; it does not create remote labels.
