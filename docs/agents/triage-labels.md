# Triage Labels

| Matt role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Needs evaluation and routing |
| `needs-info` | `needs-info` | Waiting for additional information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires a human decision or action |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a triage role, use the corresponding local `Status:` value.
